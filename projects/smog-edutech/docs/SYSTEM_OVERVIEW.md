# SMOG EDUTECH — System Overview

SMOG's work can be understood as a delivery system rather than a collection of isolated STEM lessons.

## Delivery loop

```text
Learning goals / curriculum requirements
              │
              ▼
      Curriculum progression
              │
              ▼
      Teacher preparation
              │
              ▼
       Classroom delivery
              │
              ▼
 Attendance / learner evidence
              │
              ▼
   Progress review / reporting
              │
              ▼
 Curriculum and delivery improvement
```

## Core operating components

### Curriculum
Defines progression, expected outcomes and practical activities.

### Teacher enablement
Helps instructors deliver consistently rather than depending only on personal expertise.

### Learner evidence
Attendance, completed activities, portfolios and progression make delivery observable.

### Delivery tooling
The Teacher OS concept is intended to bring lesson guidance, attendance, progress and portfolio evidence into one governed workflow.

### Physical implementation
The STEM Hub concept provides a dedicated environment for hands-on learning, teacher training and community programmes.

## Current status

The public-school implementation and curriculum work are real operating work.

Teacher OS and the STEM Hub are ongoing product/operating initiatives rather than completed production systems.
